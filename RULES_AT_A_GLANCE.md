# Rules at a Glance

Ten core rules that govern this learning operating system. Authoritative details live in the linked notes—open them for edge cases, not daily recall.

1. **One must-win outcome per day, one task in progress.** Pick the outcome before opening any code. Finish, block, or stop it before starting another. → [[LEARNING_OPERATING_SYSTEM]]

2. **Lock the plan once; replan only for a recorded reason.** [[TODAY]] is the single source of truth. Don't regenerate a new plan mid-day just because you feel like doing something different. → [[LEARNING_OPERATING_SYSTEM#Daily Plan Lock]]

3. **If AI wrote it, you still owe the learning.** Mode A for new skills (you write, AI reviews). Ownership means you can rebuild the core path from a blank file with zero assistance. → [[AI_LEARNING_PROTOCOL]]

4. **Three weekly outcomes, no more.** One flagship project milestone, one delivery/testing/reliability improvement, and one learning/interview outcome. Remove before adding. → [[CORE_SKILLS_SCHEDULE#Three Weekly Outcomes]]

5. **Evidence or it didn't happen.** Always track focus blocks with a real timer (like StudyFlow / `studyctl`). Log artifacts (tests, PRs, blank-file code), not hours watched. Mark `owned` vs `demo only` honestly. Never invent minutes. → [[LEARNING_LOG]]

6. **Search before creating.** No new lesson, note, or side-project unless there's a demonstrated blocker, an enabled artifact, insufficient existing coverage, and active work removed to make room. → [[AGENTS#Scope and Lesson Gate]]

7. **Protect sleep, commitments, and health.** Reduce the plan before reducing recovery. No catch-up marathons. Choose your capacity tier once in the morning and don't upgrade it late at night. → [[LEARNING_OPERATING_SYSTEM#Non-Negotiable Rules]]

8. **Flagship project first, defer by default.** Focus the majority of your engineering energy on your primary flagship project. Avoid touching every shiny technology unless an actual system requirement demands it. → [[CORE_SKILLS_SCHEDULE]]

9. **Closed-book redo within 48–72 hours** for any new hard skill. If you can't rebuild it without looking at the solution, it's demo-green, not owned. → [[AI_LEARNING_PROTOCOL#Closed-Book Redo Protocol]]

10. **Monthly check: what shipped, what failed, what can you explain without AI?** If a month produced only reading and no working artifact or test, rescope. → [[IAM#Monthly Check]]

---

**When in doubt:** finish the current block, log the result, and check [[TODAY]] for what's next. Obsidian is second memory, not a second backlog.
