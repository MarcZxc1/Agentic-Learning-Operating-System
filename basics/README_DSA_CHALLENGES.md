# Python DSA Challenge Path

These files are practice problems, not answer sheets. Work in this order and
write your reasoning before writing code.

## The problem-solving protocol

For every challenge, answer these questions in comments or in your notes:

1. What are the inputs?
2. What exactly should be returned?
3. What happens for an empty input?
4. Can I solve a small example by hand?
5. What information must I remember while scanning the input?
6. What is my brute-force idea?
7. Can a data structure improve it?
8. What is the time and space complexity?
